eLearning system of Pala Language Centre

Open `index.html` with VS Code Live Server. The starter uses plain CSS and
works without installing packages or running a build.

To install Tailwind when ready:

```sh
npm install -D tailwindcss @tailwindcss/cli
```

That installs the packages; the Tailwind CSS entry point and build command
can be configured in the next step. For now, `styles.css` styles the page.
The font stack prefers Inter and falls back to the system font until local
Inter assets are supplied. Light and dark colours follow the system theme.
